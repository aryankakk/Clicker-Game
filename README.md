# Clicker Game 🎮
A browser-based interactive clicking game built with **JavaScript**, **HTML**, and **CSS**.

## Features
- Dynamic difficulty levels (Easy, Medium, Hard)
- Real-time score tracking
- Separate high score tracking for each difficulty level
- Responsive design for an optimized user experience

## Technologies Used
- JavaScript
- HTML
- CSS

## Live Demo
Check out the live demo here: [Clicker Game](https://yourusername.github.io/Clicker-Game)

## How to Play
1. Select a difficulty level (Easy, Medium, or Hard).
2. Click on the circles before they disappear.
3. Track your score and aim for a new high score!
